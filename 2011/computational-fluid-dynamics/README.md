# ME282: Computational Fluid Dynamics (2011)

This folder contains Python reproductions of the archived 2011 CFD
assignments. Work is organized one assignment at a time; each notebook
includes its model, executable implementation, captured outputs, and known
uncertainties.

## Assignments

- [Assignment 3: finite-difference and finite-volume methods](assignment-3/README.md)
- [Assignment 4: nine-point accuracy and iterative solvers](assignment-4/README.md)

The Assignment 3 source bundle did not include its complete written
statement, so its notebook labels reconstructed equations. The Assignment 4
statement was identified in the archive and its requested derivations and
studies are summarized in the notebook.
