# Computational Fluid Dynamics: Assignment 4

[`CFD-Assignment-4.ipynb`](CFD-Assignment-4.ipynb) covers the nine-point
Poisson truncation-error derivation, the modified Helmholtz error and solver
convergence studies, and the Neumann Poisson example. It ports the
conjugate-gradient and Gauss-Seidel methods to Python.

Run with Python 3, NumPy, and Matplotlib. The notebook includes captured
results and plots, preserves the recorded update schemes, and flags a
discrepancy between the written Neumann boundary treatment and the recovered
implementation.
