# Assignment 4: variations, thin plates, and a hanging chain

`ME256-HW4.ipynb` is the self-contained study notebook for [ME256 Homework 4
(2011)](https://mecheng.iisc.ac.in/suresh/me256/hw2011/homework4.html).
It develops the Gateaux variation of the stated quotient, derives the thin
plate field equation and edge conditions, and compares analytical and
numerical solutions for a hanging chain.

Run the notebook with Python 3 and NumPy, SciPy, and Matplotlib, as described
in the repository README. The chain example uses fixed endpoints `(0, 2)` and
`(5, 7)`, length `12 m`, and a 15-segment discretization; the computed
multiplier and tension interpretation are included in the notebook.
